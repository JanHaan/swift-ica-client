# 15. Keyboard shortcuts

## Mac shortcuts of ICA Viewer

| Shortcut | What it does |
|---|---|
| ⌃⌥⌘L | Open the launcher from any app (can be changed or switched off in **Settings**) |
| ⌘L | Show the launcher (in ICA Viewer's own menu) |
| ⇧⌘C | Open the Connection Center |
| ⌘, | Open **Settings** (while ICA Viewer is in front) |
| ⌘Q | In a remote app: quit that app. In ICA Viewer: quit it, with the Disconnect / Log Off question |
| ⌘H | Hide the app |
| ⌘M | Minimize the window |
| ⌘W | Close the window |
| ⌘Tab | Switch between remote apps and Mac apps |
| ↩ (Return) | In the launcher: start the first or selected app |
| Esc | Cancel a dialog |

## Keys in remote apps

| You press | The remote app receives |
|---|---|
| ⌘C, ⌘V, ⌘X, ⌘A, ⌘Z | Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+A, Ctrl+Z |
| Any ⌘ letter | Ctrl with that letter (except the Mac menu shortcuts above) |
| ⌥ with a letter | The special character it makes on your Mac layout |
| ⌥ tapped alone | Alt (for example to reach a Windows menu bar) |
| ⌃ | Ctrl |

The Edit menu of a remote app (Undo, Cut, Copy, Paste, Select All) does the same as the Ctrl shortcuts.

## Mouse

The left and right buttons, the scroll wheel and the other buttons are sent to the remote app. Right-click (or Control-click) opens a Windows context menu.
